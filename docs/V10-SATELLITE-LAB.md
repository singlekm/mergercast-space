# SR-1177 — YorkAI-inspired satellite design lab
Reference: singlekm/yorkai/3d-site (README, HTML, scene and UI source inspected). Adapted three-panel controls, real Three.js 0.170.0 viewport, HUD, BOM navigator and contextual inspector to a new procedural satellite. Assembled/exploded/orbit modes, component selection, zoom, reset, motion control, JSON BOM export and existing 2D fallback. WebGL initializes only when builder is open; closes and disposes on exit. Models and budgets are illustrative, not flight CAD. No changes to YorkAI source or homepage. Device QA outstanding.
