# Mergercast Aerospace — SR-1177

Interactive React / Vite concept site for mergercast.space. Run npm install then npm run dev; npm run build produces dist. Netlify uses main, npm run build and dist. No environment variables required.

The website is a conceptual simulation only, with no live MCP, satellite or quantum services. SVG brand artwork in this repository is an interim approximation of the approved MA raster assets. Original PNGs and ICO are in the separately delivered mergercast-space-source.zip; replace interim artwork with those assets when binary upload is available. DNS is owner-managed.
